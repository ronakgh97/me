some of my works

  • blas-rs HOT! — OpenBLAS/Intel MKL implementation in pure rust, x86_64 and fp32 only.
  • hnsw-rs HOT! — generic implementation of hierarchical NSW from the paper, with hand-tuned portable SIMD in pure rust.
  • onnx-rs HOT! — minimal onnx runtime for fp32 models on x86_64 CPU, using pure rust, no python, no ffi or c++.
  • mini-db — lightweight bit-cast style, fast tokio-async KV index with WAL backend and sharding for durability and peak throughput.
  • parallelos HOT! — thread task scheduling library for HPC that implements a mixture of known scheduling algorithms.
  • esrgan-rs HOT! — original ESRGAN (16.7M params) implementation in pure rust, AVX2 for x86_64 and portable SIMD elsewhere.
  • relay — simple, superfast, duplex TCP server to transfer and receive arbitrary data from one computer to another.
  • hydra-sync HOT! — lightweight, zero copy e2e encrypted SPMC network library, used in relay clusters applications.
  • mocha — minimal cute desktop overlay tracks uptime, cpu, memory, disk, bandwidth tx/rx, keys pressed and mouse clicks.
  • missile-sim — simulates missile-target engagement scenarios using six guidance laws, used for games, sims and research purposes. [archived]
  • ghost-sync — composable async network rust library for multiplayer game dev. [archived]
